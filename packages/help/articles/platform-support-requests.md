## What this page is for

When someone using VoiceDesk can't find an answer in Help, they can click **Contact support** in the Help assistant. Their question is sent to you, the VoiceDesk team. **Platform admin → Support requests** lists every request so nothing is missed.

Only the platform owner can see this page.

## What each request shows

Each request shows:

- who sent it and their email address;
- the business they were using (if any);
- the page they were on;
- their message;
- when it was sent, and whether it's **Open** or **Resolved**;
- the help conversation, if they ticked **Include this help conversation** (open it to read it).

Each request is also emailed to you when it arrives. Replying to that email goes straight to the person who asked.

## Replying to a request

Replies go by email, not inside VoiceDesk.

1. Read the message (and the shared help conversation, if there is one).
2. Click **Reply by email**. Your email app opens with their address filled in. You can also reply to the notification email.
3. If the answer would help others, add it to the Help articles too.

Don't ask people to send passwords, API keys or customers' personal details by email.

## Marking a request resolved

Once you've replied and the problem is sorted, click **Mark resolved**. Open requests are listed first and resolved ones move below them, so you can see at a glance what still needs an answer. Click **Reopen** if it comes back. The **Setup** page also shows how many requests are open.

## Spotting patterns

If several people ask the same thing, that's a sign a screen is confusing or a Help article is missing. Note it for the next round of improvements.
